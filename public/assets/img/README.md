# Logo folder

Upload the official Seafood City logo here as **`logo.png`** (this exact name).

- Full path: `public/assets/img/logo.png`
- On GitHub: open this folder → **Add file → Upload files** → drop your image renamed to `logo.png`.
- A wide horizontal lockup works best; the header sizes it to ~42px tall.

Once `logo.png` is here, every page header uses it automatically. Until then,
the headers fall back to `logo-mark.svg` (the red diamond-fish placeholder).
